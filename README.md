# 💼 Job Portal (MERN + TypeScript)

A full-stack **Job Portal application** built with the MERN stack and TypeScript.  
This platform connects **Job Seekers** and **Recruiters** with role-based dashboards, authentication, and a smooth user experience.

---

## 🚀 Features

### 👤 Authentication & Authorization
- Secure **JWT authentication**
- Role-based access (**Job Seeker / Recruiter**)
- Login & Registration with form validation

### 🧑‍💻 Job Seeker
- Browse & search jobs with filters  
- View job details  
- Apply to jobs  
- Manage profile  

### 🏢 Recruiter
- Post new jobs  
- Manage (edit/delete) jobs  
- View applicants for posted jobs  
- Recruiter profile management  

### 📊 Extras
- Job statistics (total jobs, applications, top applied jobs)  
- Dashboard with role-specific UI  
- Toast notifications and form validations  
- Fully deployed with **Render**  

---

## 🛠️ Tech Stack

### Frontend
- React + Vite  
- TypeScript  
- TailwindCSS + ShadCN/UI  
- Axios + React Hook Form  

### Backend
- Node.js + Express.js  
- MongoDB + Mongoose  
- TypeScript  
- JWT Authentication + Middleware  

### Deployment
- Render (Backend + Frontend)
